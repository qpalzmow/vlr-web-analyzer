# VLR Web Analyzer

FastAPI, SQLite 및 일반 JavaScript로 구성된 VLR 경기 분석기입니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python server.py
```

기본 포트는 7860이며 PORT 환경변수로 변경할 수 있습니다.

## 캐시와 대회 선택

- 대회를 선택하지 않으면 전체 기간의 팀 통계를 사용합니다.
- 대회를 선택하면 해당 대회만 집계합니다. 기록이 없는 대회에는 다른 기간의 데이터를 대신 표시하지 않습니다.
- 대회는 양 팀의 최근 목록을 합쳐 최대 24개까지 선택할 수 있습니다.
- SQLite 팀 캐시는 지표별로 1시간이 지나면 재조회합니다. 일부 지표의 갱신이 다른 지표의 유효기간을 연장하지 않습니다.
- 이전 버전의 캐시는 최초 시작 시 추가 컬럼으로 마이그레이션합니다. 기존 데이터를 삭제하지 않으며 집계 범위를 확인할 수 없는 통계는 다시 수집합니다.
- 경기 점수는 상세 캐시와 별도로 조회합니다. 선택 직후 확인하고 LIVE는 25초, UPCOMING은 60초 간격으로 갱신합니다. 일시적인 오류에는 재시도하며 FINAL이면 중지합니다.

## 자동 동기화 및 수동 관리

자동 동기화는 서버 시작 후 일정 주기로 실행됩니다. SQLite의 5분 임대 잠금을 1분마다 갱신하여 여러 프로세스의 중복 수집을 막습니다. 프로세스가 비정상 종료돼도 임대 만료 후 다음 스케줄러 확인에서 다시 실행할 수 있습니다.

`POST /api/sync/trigger` 및 `POST /api/cache/warm`은 기본적으로 비활성화(503)되어 있습니다. 수동 실행이 필요하면 서버의 VLR_MAINTENANCE_TOKEN 환경변수에 별도의 비밀값을 설정하고, 요청의 Authorization 헤더에 `Bearer <설정한 값>`을 전달합니다. 토큰을 화면 JavaScript에 넣지 마세요. 인증 실패는 401, 이미 실행 중이면 409, 직전 수동 실행 시작 후 5분이 지나지 않았으면 429를 반환합니다. 이 설정은 자동 동기화에 영향을 주지 않습니다.

## 테스트

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
node --test tests/frontend.test.cjs
```

Python 테스트는 임시 SQLite DB와 대체 수집 함수를 사용합니다. 프런트엔드 테스트는 Node의 내장 테스트 도구와 DOM 대체 객체로 경기 선택, 필터, 공유 링크, 점수 갱신, 차트를 검증합니다. 실제 VLR 연동, 실제 브라우저, Docker 실행 검증과는 구분됩니다.
